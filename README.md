## Features

- Single-page layout with navigation between sections.
- Responsive layouts for desktop and mobile
- Three project cards with screenshots, descriptions and links
- Project thumbnail images optimized to less than 200 KB each.
- Technology icons and a seperate section for coursework experience
- About section with an illustrated avatar.
- Downloadable CV and cover letter.
- Email and GitHub contact links.
- External website links to open in a new tab.
- Keyboard focus styles and a skip-to-content link.
- CSS hover effects on project cards and buttons.

## Technologies used

- HTML5
- CSS3, including flexbox, grid and media queries
- SVG images for technology icons

No CSS frameworks or JavaScript libraries are used.

## Getting started

### Installation

Clone the repository:

```bash
git clone https://github.com/tommyaarstein/Portfolio_1.git
```

Open the project folder:

```bash
cd Portfolio_1
```

There are no packages to install and no build step.

### Running locally

Open the project in VS Code and use the Live Server extension to serve `index.html`.

Then you can also visit the page in your preferred browser using:

```text
http://localhost:3000
```

## Usage

Use the navigation links to move between Projects, About and Contact.

Each project card has links to its live website and GitHub repository. The About section contains downloads for my CV and cover letter.

The email link opens your default email application.
